# KOKO VR
A game inspired by AOT where you play as the Colossal Titan and attempt to break through Wall Maria. Will you be the hunter or be the hunted? Avoid horses and cannon's at all cost! Otherwise, your attempts will be futile...

To run it locally run `git clone https://github.com/ryan-mai/koko.git` > `python serve.py` > http://localhost:####
